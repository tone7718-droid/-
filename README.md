# ROM Vision Tool

**실시간 관절 가동범위(ROM) 측정 및 피드백 자동화 애플리케이션**

---

## 개요

카메라 또는 영상 입력을 통해 피사체의 움직임을 분석하고,  
관절 가동범위(Range of Motion)를 실시간으로 측정·시각화·피드백하는 AI 툴.  
기능 부전 근육 재활 훈련 및 운동 교정에 활용 가능.

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| 실시간 포즈 감지 | 카메라 프레임을 분석해 관절 좌표 추출 |
| ROM 각도 계산 | 주요 관절(어깨, 고관절, 무릎, 발목 등)의 가동범위 측정 |
| 기능 부전 판별 | 정상 ROM 범위 대비 비교 분석 |
| 실시간 피드백 | 음성 or 텍스트로 교정 가이드 제공 |
| 세션 기록 | 시간별 ROM 변화 추이 저장 |

---

## 기술 스택

- **AI 모델:** Claude Fable 5 (`claude-fable-5`) — 비전 분석 및 피드백 생성
- **포즈 추정:** MediaPipe Pose / OpenCV (로컬 처리)
- **프론트엔드:** React Native (모바일 앱)
- **백엔드:** FastAPI (Python)
- **저장소:** SQLite / Firebase

---

## 시스템 구조

카메라 입력
↓
[로컬 포즈 추정 - MediaPipe]
↓ 관절 좌표 + 프레임 이미지
[Fable 5 API - 비전 분석]
↓ ROM 수치 + 이상 감지
[피드백 생성 루프]
↓
사용자 화면 + 음성 피드백
